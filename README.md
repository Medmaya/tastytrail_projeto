# 🍽️ TastyTrail

O **TastyTrail** é um projeto acadêmico desenvolvido em dupla por **Mayara Medeiros** e **Vitor Lima**, durante o 2º semestre do curso de Sistemas de Informação das Faculdades Integradas Rio Branco, na disciplina de Lógica de Programação.

## 🎯 Sobre o projeto

O TastyTrail é um site web de delivery desenvolvido com o objetivo de colocar em prática os conhecimentos de lógica de programação utilizando Python, além de explorar o desenvolvimento de uma aplicação com funcionalidades voltadas à experiência do usuário.

A plataforma permite que os usuários realizem **login e façam pedidos**, simulando o funcionamento de um serviço de delivery online.

## ✨ Funcionalidades

- 🔐 **Login de usuários:** acesso à plataforma por meio de autenticação.
- 🛍️ **Realização de pedidos:** possibilidade de selecionar e solicitar produtos pela plataforma.
- 🌐 **Interface web:** interação com o sistema por meio de um site.

## 🛠️ Tecnologias e conhecimentos

- **Python** — prática de lógica de programação e desenvolvimento.
- **Git e GitHub** — versionamento e compartilhamento do código-fonte.

## 📚 Objetivos de aprendizagem

- Desenvolver o raciocínio lógico e a capacidade de resolução de problemas.
- Aplicar conceitos fundamentais de programação.
- Praticar a construção e a organização de código.
- Compreender a lógica por trás de funcionalidades como login e realização de pedidos.
- Desenvolver habilidades de colaboração por meio de um projeto em dupla.
